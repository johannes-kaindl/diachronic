# Send a note back and take over the answer

## Send back

Run *Send back*. If you changed the text but did not mark the changes, a notice offers *Mark first* or *Send anyway*. Then the round in the properties counts up, the stand "Round N – outgoing" is saved and the share sheet opens with the note.

## Take over a returned file

When a file with the same document id as one of your notes appears in the vault under another name (for example "Letter (1).md"), a notice offers *Take over as round N*. You can also open the file and run *Take over this file as the next round*.

1. Diachronic compares your note with the stand you sent. If **both** your note and the returned file changed since then, **nothing is written**: a comparison shows the difference and you decide by hand.
2. Otherwise you confirm. The current text of your note is saved as a stand, the content of the returned file goes into your note, the stand "Round N – incoming" is saved, and the copy goes to the trash (as set in Obsidian).
3. If the returned file holds changes that are **not marked**, Diachronic offers to compare them with what you sent and mark them as suggestions by the sender (name from the participants, or you type it).

## A file with an unknown id

A returned file whose id this vault does not know (for example the colleague's first answer) can be taken over into a note you choose, or kept as a new document. Taking it over into a note replaces that note's text; the old text is saved as a stand first.
